# PREINIT Files

Preinit files are simply scripts ARES runs on start up, they are stored under `$HOME/System/Programs/ARES/preinit.ares`
And you can with it call another preinit.ares scripts, or bash scripts(these won't be able to properly interact with ARES because... that's just how ARES works.)

for more information about the AEX Syntax. Look at [The AEX MicroDoc](../../src/include/modules/AEX/README.md) or the [APOSI Docs](https://softworks.aizawallc.org/APOSI/)
> Note: Some features of the APOSI docs might be buggy.
> We are working on it.
